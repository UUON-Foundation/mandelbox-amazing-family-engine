What This Engine Is
UUON Amazing Family is a real-time ray marching fractal renderer running entirely on the GPU via WebGL2 GLSL. No polygon mesh — geometry is pure math, traced pixel by pixel every frame. Part of the UUON PHRAMEWORK anchored to Base Mainnet via genesis hash.
Ray Marching
For every pixel, a ray fires from the camera and asks: "how far to the nearest surface?" A Distance Estimator (DE) answers. The ray steps forward by exactly that safe distance, asks again. When distance drops below a threshold, it has hit.
MAX_STEPS128–256 per ray before giving up
SURF_EPSHit threshold — scales with iter depth
STEP_FAC0.5× safety — prevents overshooting
BOUND_R2Bounding sphere r=8 — outside skips DE
The Four Fractals
MandelboxTom Lowe, 2010. Box fold + full 3D sphere fold. Solid crystalline volumes.
Amaz SurfKnighty, 2011. XY-only sphere fold. Z escapes — infinite layered surfaces.
Surf Mod1Amaz Surf + fixed Julia offset. Breaks translational symmetry.
Box JuliaMandelbox with constant c. Reveals the attractor skeleton.
F=(P,E,M,R,C) Formulation
P{ mode, iter, scale, fold, minR, fixR } — 6 values ~48 bytes
EGLSL DE function applied per ray, per pixel, every frame
MCompile-time MODE dispatch + upU() uniform chain — maps P to GPU behavior
RWebGL2 framebuffer (live) · PNG · OBJ mesh with vertex normals
CP=48B → R≈180KB–2MB → C≈3,750:1 to 40,000:1
